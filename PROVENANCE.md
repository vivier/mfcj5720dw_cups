# Source and data provenance

This is an independent reverse-engineered driver for the Brother MFC-J5720DW.
It is not an official Brother release. Project-specific source code, build
files and documentation were generated by OpenAI Codex under the direction
of Laurent Vivier. The sources reconstruct the printing pipeline studied in
the original Brother driver; subsequent changes include the direct CUPS
interface, native data structures and a libjpeg adapter.

The factory-calibration reader reconstructs the read-only SNMP retrieval
protocol studied in Brother's Windows and macOS drivers. Printer-specific
snapshots are read from the device at runtime; no captured snapshots or
original vendor executables are included in this repository.

## Gutenprint PackBits implementation

`encoder/packbits.c` contains `stp_pack_tiff()` and `find_first_and_last()`,
extracted from Gutenprint's
[`src/main/bit-ops.c`](https://sourceforge.net/p/gimp-print/source/ci/11a6edb87d36ed0e51a8ece5ad36815202dd2f12/tree/src/main/bit-ops.c)
at commit `11a6edb87d36ed0e51a8ece5ad36815202dd2f12`.
The function bodies retain their upstream code. Only the includes and the
local `NOINLINE` definition were adapted for standalone compilation.

The copyright is held by Charles Briscoe-Smith (2000), and the code is licensed
under GPL-2.0-or-later. Its existing notices remain in the source. The local
header declares the unused opaque `stp_vars_t` parameter so the function
signature remains intact. No Gutenprint library is required.

## Brother calibration data

The calibration data originate from Brother's
[`mfcj5720dwlpr-3.0.1-1.i386.rpm`](https://download.brother.com/welcome/dlf101184/mfcj5720dwlpr-3.0.1-1.i386.rpm).
Its SHA-256 is:

```text
58c5f451b07fc4470edbe1b5f112f2bf784e124f8170230ca9e4d8aa888a78a9
```

The original RPM metadata declares:

```text
2003-2014 Brother Industries, Ltd. All Rights Reserved
```

The ten retained `lut/*.xml` profiles and shared tables in `lut/cubes/*.xml` and
`lut/curves/*.xml` are lossless textual transcriptions of Brother's BCM
profiles. The XML-to-BCM compiler generates the profiles used at runtime.
Embedded copyright strings, calibration values and uninterpreted bytes are
retained. XML storage does not create new ownership of the underlying data.
The unused `BRPRI14AK.BCM` profile and its exclusive XML tables were removed.

The nine `encoder/*_tables.c` files contain transcriptions of numerical data
used by the driver: color interpolation and calibration, dither thresholds,
diffusion noise, enhancement kernels, halftone settings, paper geometry,
media choices, printhead selectors and swath schedules. Their numerical
values and lookup order come from the original driver. Native C pointers
replace the original executable's fixed addresses and callback relocations.

These Brother data retain their existing notices and terms. The project GPL
notice does not relicense them. The RPM uses `LicenseRef-Brother-Data` to
identify this exception, not to claim that Brother granted a new license.

The original RPM's [download page](https://support.brother.com/g/b/downloadend.aspx?c=us&lang=en&prod=mfcj5720dw_us_eu_as&os=127&dlid=dlf101184_000&flang=4&type3=558)
links to Brother's [LPR license agreement](https://support.brother.com/g/s/agreement/English_lpr/agree.html)
(checked on 2026-11-13). That agreement permits reproduction, distribution,
modification and distribution of derivatives, while retaining Brother's
copyright. Acceptance of these terms for Fedora COPR has not been established.

## System libraries and build tools

The driver dynamically links against system CUPS and libjpeg. The recommended
JPEG implementation is libjpeg-turbo. Their source code is not included.
The Python profile compiler uses the standard library. The PPD is generated
from `mfcj5720dw.drv` by CUPS `ppdc`.

No original Brother executable, original binary data section or LPR wrapper
is needed to build or run this repository. Generated BCM profiles are runtime
data; the printer encoder itself is compiled from the included C sources.
